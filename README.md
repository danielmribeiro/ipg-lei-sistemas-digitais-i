## Course Objectives
Upon completion of this course, students should be able to:
1. Represent and operate with rational numbers in different numbering bases.
2. Represent and operate real numbers in true and false complement form.
3. Codes.
4. Represent and simplify functions of binary variables using Boolean algebra.
5. Simplify functions using Karnaugh maps.
6. Arithmetic circuits. Assembly of some circuits.
7. Design with multiplexers, decoders, and ROM.

## Program Contents
### Numbering Bases
- Representation of integers in bases 2, 8, and 16.
- Base conversion.
- Operations in the mentioned bases.
- Representation of numbers smaller than one in bases 2, 8, and 16.
- Concept of representation precision.
- Base conversion and related operations.
- Representation of real numbers in complement form.
- Numeric, alphanumeric, and reflected codes.
- BCD and BCD excess-3 codes.
- Addition algorithms.

### Logical Functions
- One- and two-variable logic functions.
- NOT, AND, and OR functions.
- Formal definition of Boolean algebra.
- Duality and operation priority.
- Theorems.
- NAND, NOR, and XOR functions.
- Multi-variable functions.
- Canonical disjunctive and conjunctive normal forms.
- Representation using a single type of gate.
- Minimization of logical expressions.

### Introduction to Digital Electronics
- Brief study of diodes, transistors in switching, and logic gates.
- Physical implementation of logic circuits.
- Digital integrated circuits and their assembly.

### Boolean Simplification Using Karnaugh Maps
- Boolean simplification using Karnaugh maps for both canonical normalized forms.
- Maps for 2, 3, 4, 5, and 6 variables.

### Arithmetic Circuits
- Full adders and subtractors.
- Fast adders.
- Subtraction using adders.
- Adder-subtractor circuit.
- Matrix multiplier for unsigned numbers.

### Medium Complexity Combinational Modules
- Decoders, encoders, multiplexers, and demultiplexers.
- Design using decoders and multiplexers.
- Direct circuit implementation using ROM.
- ROM structure.
- Iterative circuits.

## Learning Methodologies

## Assessment Criteria
- Two written tests worth 30% each, with a minimum score of 7 points.
- Laboratory assignments worth a total of 40%.
- In the resit or special exam period, the exam is worth 60%.
